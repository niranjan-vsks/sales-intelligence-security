# P0: Repository scaffold, conventions, test harness

Model: Sonnet 5.5. Day 1, first half.

## Goal

A repository layout, configuration system, CLI skeleton, test harness and
CI file that every later card plugs into without renegotiating structure.
After P0, `uv run sis --help` lists every pipeline command as a stub and
`uv run pytest` passes.

## Read first

DESIGN.md sections 2 and 10. DATA_MODEL.md conventions block at the top.
findings/queries/common.py (the explorer's DuckDB setup; reuse its
settings).

## Depends on

Nothing.

## Inputs

None from data. The raw file and the explorer's Parquet are not touched.

## Steps

1. `uv init`, set python 3.12, add dependencies above. Commit the lockfile.
2. Write `sis/config.py`, `sis/paths.py`, `sis/db.py`, `sis/log.py` as
   specified. `db.connect()` must work with no `SIS_DATA` directory present
   (create `duckdb_tmp` lazily).
3. Write the typer CLI with all 10 stubs.
4. Write `config/scoring.yaml` by copying DESIGN.md 5.2 and 5.3 into
   YAML: keys `facts.a.weights`, `facts.b.weights`, `facts.c.weights`,
   `facts.d.weights`, `exposure.weights {a,b,c}`, `segments.multipliers`,
   `peer.breadth_buckets: [[1,1],[2,3],[4,9],[10,null]]`, `scoring_version`.
   Write `sis/scoring_config.py` with a pydantic model that loads and
   validates it (weights are floats in [0, 2]; exposure weights sum to 1.0
   within 1e-9).
5. Build the fixture: `zstd -dc <raw file> | head -n 200 > tests/fixtures/tiny_banners.jsonl`.
   Check the file is under 2 MB; if the 200 lines exceed that, drop the
   largest lines until under 2 MB and note which were dropped in a
   `tests/fixtures/README.md`.
6. Write `tests/conftest.py` so that `tiny_banners` runs the explorer's
   flattener logic (import from `findings/queries/01_flatten.py` for now;
   P1 moves it) to produce Parquet in `tmp_path`.
7. Write the CI file. Mark pytest markers `eval` and `llm` in
   `pyproject.toml` so unmarked runs skip them.
8. README.
