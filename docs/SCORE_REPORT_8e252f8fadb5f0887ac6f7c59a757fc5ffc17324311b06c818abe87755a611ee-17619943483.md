## Reviewer note: hosting providers dominate the top of the ranking

The top 20 above are all hosting or colocation providers, not tenants: OVH's per-/24 reverse
DNS zones (`ip-15-235-134.net`, `ip-54-36-168.eu`), and hosters such as hostinguk.net,
liquidweb.com, hostcentral.net, prioritycolo.com, l1servers.com. Each zone stays under the
50-IP cutoff (OVH splits its rDNS by /24), so P2 keeps it as a customer entity, and it then
aggregates many unrelated customers' servers, which maximises breadth, admin services and
end-of-life findings. Measured on this run (query in the P3 handoff):

| top k | `ip-a-b-c.` zones | names matching host/server/hosting/cloud/colo/isp/vps/datacenter or `ip-` |
|---|---|---|
| 100 | 22 | 45 |
| 1,000 | 193 | 398 |
| 10,000 | 739 | 1,812 |

6,640 active entities have an `ip-a-b-c.` key. This is a P2 operator-detection gap surfacing
in P3, not a scoring bug; P3 implements the card as written. Fixing it is a design decision
(an `ip-N-N-N.` pattern rule and/or an org-equals-hoster rule in P2), left to the architect.
