Count versus the explorer: 485,089 customer-domain entities there; here 481,186 active + 343 blocked domain-kind = 481,529 (-3,560, -0.73%). Causes, not separately measured: names the explorer kept raw are merged or dropped by normalisation (`www.` prefix, case, trailing dot, non-host strings); the derived operator list is 3,777 names against the explorer's 3,152 over-cutoff domains because it also takes certificate and Host names above the cutoff; IP coverage uses `coalesce(ip_str, ipv6)`.

Clarification of the card, recorded as a deviation: a certificate or Host name above the cutoff in its own kind is still attributed when it also exists as a primary domain entity (step 6 re-key applied to coverage). Without this, 4,729 banners ended up `over_cutoff`, which the card requires to be 0; with it, over_cutoff is 0 by construction and 38,433 banners are fallback-attributed.
