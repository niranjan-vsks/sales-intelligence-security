## What a real second delivery would add

This file differs from the first only where `sis synth` changed it, so every event has a cause that is written down. A real delivery would add what a simulation cannot: re-observation gaps (a service the scanner missed this time, which looks like `service_gone` and is not), banners that were never in the first file, genuinely new entities and domains, certificates renewed rather than expired, and changes nobody planned. The diff logic is the same; what changes is how much of its output is noise, and the first real pair is where that is measured. Only 2 files are compared at a time; windows of 3 or more files (to treat a missed observation as still present) are described in DESIGN.md section 8 and not built.
